# remake.shiyanshirani

Maximalist React remake of `shiyanshirani.github.io`.

## Stack

- React + Vite + TypeScript
- Tailwind CSS
- shadcn-compatible structure
- `motion.dev` animations

## Notes

- Nohemi font files are referenced from `src/assets/fonts/`.
- Add licensed font files before expecting true Nohemi rendering:
  - `Nohemi-Regular.woff2`
  - `Nohemi-Regular.woff`
  - `Nohemi-Bold.woff2`
  - `Nohemi-Bold.woff`
- This machine currently has no Node package manager installed, so dependencies were not installed and the app was not built locally.
